# Contributing

Thanks for helping improve this base .github repository. Changes here affect all Ven0m0 repositories that rely on default community health files and workflows.

If the target repository includes its own CONTRIBUTING.md, follow that guidance first.

## How to contribute
1. Search existing issues and discussions before starting new work.
2. Open an issue for significant or user visible changes.
3. Create a branch from main and keep changes focused.
4. Update documentation and examples alongside code changes.
5. Validate workflows in a sandbox repository when possible.

## Pull requests
- Use the pull request template.
- Include rationale, scope, and any backward compatibility notes.
- Add or update tests where applicable.
- Do not include secrets or sensitive data.

## Commit guidance
Use conventional commits with clear messages. Examples: feat, fix, docs, chore, refactor, test.

## Code of conduct
This project follows CODE_OF_CONDUCT.md.

## Security
Report vulnerabilities via SECURITY.md. Do not file public issues for sensitive reports.
